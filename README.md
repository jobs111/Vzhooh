# ВЖУХ-Х (Vzhooh)

Личный мессенджер «по QR-коду»: чат, файлы, голосовые сообщения, аудио- и видеозвонки один на один.
Работает как сайт (GitHub Pages), без аккаунтов и без собственных серверов.

## Как пользоваться

**Владелец**
1. Открыть сайт → «Новый чат» → выбрать режим → «Создать».
2. Отправить собеседнику ссылку или показать QR-код.
3. Когда собеседник откроет ссылку, чат соединится сам.

**Собеседник** — просто открыть ссылку или навести камеру на QR-код.

**Перекинуть что-то на чужой компьютер** — открыть сайт на компьютере: он покажет QR-код.
Владелец наводит на него камеру телефона, и между телефоном и компьютером открывается чат.

## Режимы

| | Быстрый | Защищённый |
|---|---|---|
| История | на устройствах, до срока жизни чата (1–48 ч) | не сохраняется нигде |
| При закрытии | чат остаётся, можно вернуться | всё стирается у обоих |
| Автоудаление сообщений | — | таймер 30 с – 1 ч |
| Шифрование | сквозное в обоих режимах | сквозное в обоих режимах |

В любом режиме есть «Удалить всё у обоих», «Разорвать соединение» и «Код безопасности» (значки, которые можно сверить с собеседником).

## Как это устроено

- **Сайт** — статические файлы. После первого открытия работает из кэша.
- **Соединение** — устройства находят друг друга через публичные MQTT-серверы (ретрансляторы). Они видят только зашифрованные данные.
- **Прямая связь** — после знакомства устройства соединяются напрямую (WebRTC). По прямой связи идут файлы любого размера и звонки.
- **Запасной путь** — если напрямую соединиться не удалось, текст, голосовые и небольшие файлы (до 600 КБ) идут через ретрансляторы. Звонкам нужна прямая связь.
- **Шифрование** — только встроенная в браузер криптография (WebCrypto): ECDH P-256 → HKDF → AES-256-GCM. Секрет приглашения находится в части ссылки после `#` и не уходит на веб-сервер.
- **Только владелец** — файл `public/owner.json` содержит открытый ключ владельца. Создавать чаты может только тот, кто знает пароль владельца; чужие «комнаты» приложение отклоняет. Пока файл пустой (`{}`), сайт не закреплён и создавать чаты может любой.

## Разработка

```bash
npm install
npm run dev      # локальный сервер
npm run build    # сборка в dist/
npm test         # сквозные тесты (нужен Playwright с Chromium)
```

Диагностика сети — кнопка 🩺 на главном экране: показывает, какие серверы доступны с устройства.

## Публикация

Сборка и публикация выполняются автоматически (GitHub Actions → GitHub Pages) при каждом обновлении ветки.
В настройках репозитория: **Settings → Pages → Source: GitHub Actions**.
