# ВЖУХ-Х (Vzhooh)

Личный мессенджер «по QR-коду»: чат, файлы, голосовые, аудио- и видеозвонки, раздача файлов.
Работает как сайт (GitHub Pages), без аккаунтов и без собственных серверов.

## Что умеет

| Функция | Как пользоваться |
|---|---|
| **Чат 1:1** | «Новый чат» → ссылка или QR → собеседник открывает → соединились |
| **Много устройств одним QR** | «Новый чат» → «Много устройств»: каждый, кто отсканировал, получает свой отдельный чат |
| **Комната для звонка** | «Звонок» → голосовой или видео → отправить QR → звонок начнётся сам |
| **Раздача файла** | «Раздать файл» → выбрать файлы → QR/ссылка на срок до 48 ч; скачивать может кто угодно по ссылке |
| **QR из ссылки** | «QR из ссылки» → вставить ссылку → скачать PNG или показать на весь экран |
| **Компьютер без входа** | Открыть сайт на чужом компьютере → он покажет QR → навести телефон |
| **Демонстрация экрана** | Кнопка 🖥 во время звонка (на компьютере) |
| **Удалить сообщение у всех** | Нажать на своё сообщение → «Удалить у всех» |

Режимы чата: **Быстрый** (история на устройствах, чат живёт 1–48 ч) и **Защищённый**
(ничего не сохраняется, автоудаление сообщений, при закрытии всё стирается у обоих).
Связь пропала — приложение переподключается само и пишет об этом.

## Как это устроено

- **Сайт** — статические файлы; после первого открытия работает из кэша.
- **Знакомство устройств** — через публичные MQTT-ретрансляторы. Они видят только зашифрованные данные.
- **Прямая связь (WebRTC)** — файлы любого размера и звонки идут напрямую между устройствами.
- **Запасной путь** — без прямой связи текст, голосовые и файлы до 1 МБ идут через ретрансляторы. Звонкам нужна прямая связь.
- **Раздача файлов** идёт с устройства владельца: пока приложение открыто, файлы можно скачать.

## Безопасность

- Шифрование — только встроенная криптография браузера (WebCrypto): ECDH P-256 → HKDF → AES-256-GCM, у каждого сеанса свой ключ.
- Секрет приглашения находится после `#` в ссылке и не уходит на веб-сервер.
- Создавать чаты, звонки и раздачи может только владелец (файл `public/owner.json` + пароль владельца). Чужие «комнаты» приложение отклоняет.
- Политика безопасности контента (CSP) запрещает выполнять посторонние скрипты и подключаться к посторонним адресам.
- Код сайта по природе веба виден браузеру; защита держится не на скрытности кода, а на ключах, которых нет ни в коде, ни на сервере.

## Разработка

```bash
npm install
npm run dev      # локальный сервер
npm run build    # сборка в dist/
npm test         # сквозные тесты (Playwright + Chromium)
```

## Публикация

GitHub Actions собирает сайт и публикует его на GitHub Pages при каждом обновлении главной ветки.
